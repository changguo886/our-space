# Our Space refined illustration pack

Contains 16 RGBA cat PNG illustrations (512x512), five scenic WebP images (opaque backgrounds), and an original concept sheet (reference only).

## Production notes

- Use character PNGs from `/assets/growth/characters/cat_*.png`.
- Use scenic WebPs from `/assets/growth/seasons/*.webp`.
- Existing simplified SVG cats remain present for compatibility; update component references deliberately.
- Automated alpha extraction can leave edge artifacts. Perform visual review at actual render sizes before merging.
- The source concept sheet is NOT shipped to the public directory.
